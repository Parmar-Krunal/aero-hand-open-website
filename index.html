Aero Hand Open

Start the local launcher to bring up the website, CAD viewer, and digital-twin service together. Once all three services are ready, this page opens the website automatically.

Preview the website only Local setup instructions

To start locally, open this project folder in File Explorer and double-click START_WEBSITE.bat. It starts ports 8765 (website), 3245 (CAD), and 8888 (digital twin). Opening this HTML file by itself cannot start server processes.

For static hosting, publish this folder with its subfolders intact. The preview works there, but local CAD and digital-twin services must be hosted separately.
