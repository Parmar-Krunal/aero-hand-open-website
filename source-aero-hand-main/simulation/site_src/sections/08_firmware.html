Supported Protocol Opcodes

Opcode Name Direction Function
0x01 CMD_HOMING Host → ESP Executes full 7-servo homing routine; saves endpoints in NVS.
0x02 CMD_SET_ID Host → ESP Scans bus and programs servo IDs (0 to 6) and current limits.
0x11 CTRL_POS Host → ESP Sends 7 position setpoints (0–65535 mapped to calibrated servo range).
0x12 CTRL_TOR Host → ESP Commands torque/current mode for direct compliance control.
0x22 GET_POS ESP → Host Returns 7 normalized actuator positions in little-endian uint16.
0x24 GET_CURR ESP → Host Returns 7 actuator currents (signed integer, 1 unit = 6.5 mA).
