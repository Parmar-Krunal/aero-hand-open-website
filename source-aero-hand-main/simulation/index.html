⚡ Power Rail Isolation: The 6 V external servo rail (XT30 connector J8) powers only the smart servos and is kept strictly separate from the USB 5 V logic rail. Connecting 6 V to ESP32 GPIO or USB VBUS will destroy the microcontroller.
Hardware Protection Features
• SN74LVC1G126 & SN74LVC1G125: High-speed tri-state bus buffers for half-duplex UART arbitration.
• 100 mA PTC Resettable Fuse: Protects MCU GPIO against accidental bus short-circuits.
• Decoupling & Filtering: 100 µF bulk electrolytic + 100 nF ceramic capacitors smooth motor inrush currents.

Bidirectional Bridge & Sensor Telemetry

digital_twin_bridge.py Features
• Real Hand → Sim: Polls physical hand at 50 Hz, converts 7 actuator counts → 16 URDF joint angles, publishes to Gazebo topics or WebSocket.

• Sim → Real Hand (Mirror Mode): Reads simulator slider/pose outputs, translates through inverse tendon model, and commands physical servos.

• FSR Sensor Ingestion: Connects to an Arduino running aero_hand_fsr_sensor.ino on a second COM port, reading 5 channels of tactile force (0–15 N) and piping into the twin.
Bridge Command-Line Reference
# Stream real hand to Gazebo & WebSocket:
python simulation/digital_twin_bridge.py --port COM3 --ws

# With Arduino FSR pressure sensors:
python simulation/digital_twin_bridge.py --port COM3 --sensor-port COM4

# Mirror mode (Sim drives hand):
python simulation/digital_twin_bridge.py --port COM3 --mirror

# Standalone dry-run demo:
python simulation/digital_twin_bridge.py --dry-run

Supported Protocol Opcodes

Opcode Name Direction Function
0x01 CMD_HOMING Host → ESP Executes full 7-servo homing routine; saves endpoints in NVS.
0x02 CMD_SET_ID Host → ESP Scans bus and programs servo IDs (0 to 6) and current limits.
0x11 CTRL_POS Host → ESP Sends 7 position setpoints (0–65535 mapped to calibrated servo range).
0x12 CTRL_TOR Host → ESP Commands torque/current mode for direct compliance control.
0x22 GET_POS ESP → Host Returns 7 normalized actuator positions in little-endian uint16.
0x24 GET_CURR ESP → Host Returns 7 actuator currents (signed integer, 1 unit = 6.5 mA).

High-Level Robotics API

Python SDK & Control

Clean, idiomatic Python library for controlling the Aero Hand Open. Includes kinematic forward/inverse mapping, trajectory smoothing, live telemetry, and an interactive calibration GUI.

Package Install
pip install aero-open-sdk
Launch Calibration GUI
aero-open-gui
Install from Local Source
cd sdk && pip install -e .
Basic Position Controlsdk/examples/joint_control.py
from aero_open_sdk.aero_hand import AeroHand

# Connect via USB serial (COM3 on Windows, /dev/ttyACM0 on Linux)
hand = AeroHand(port="COM3", baudrate=921600)

# Run homing routine (required on initial startup)
hand.send_homing()

# Command 7 joint angles in degrees:
# [thumb_abd, thumb_flex, thumb_mcp, index, middle, ring, pinky]
hand.set_joint_positions([45.0, 25.0, 40.0, 75.0, 75.0, 75.0, 75.0])

# Read back live telemetry
currents = hand.get_actuator_currents()
print("Actuator currents (mA):", currents)

hand.close()
Trajectory Playback at 100 Hzsdk/examples/run_sequence.py
from aero_open_sdk.aero_hand import AeroHand

hand = AeroHand(port="COM3")

# Define keyframes: (7-dof pose degrees, duration seconds)
gestures = [
    ([0, 0, 0, 0, 0, 0, 0],         0.8),  # Open palm
    ([45, 30, 50, 80, 80, 80, 80],   1.2),  # Full power grasp
    ([10, 10, 10, 20, 0, 0, 0],      1.0),  # Peace sign
    ([0, 0, 0, 0, 0, 0, 0],         0.8),  # Reset
]

# Executes cubic/linear spline interpolation smoothly
hand.run_trajectory(gestures)
hand.close()

ros2 run aero_hand_open aero_hand_node

# Terminal 2: RL deployment node
ros2 run aero_hand_open_rl rl_z_rotation_deploy
