Robotics Middleware

ROS 2 & Teleoperation Suite

Built for ROS 2 Humble Hawksbill. Includes low-latency serial hardware bridges, teleoperation retargeting from Manus data gloves or MediaPipe vision, and reinforcement learning policy deployment.

Hardware Driver
aero_hand_open
Subscribes to joint and actuator command topics. Streams actuator feedback at 100 Hz.
/aero_hand/joint_control
/aero_hand/actuator_control
/aero_hand/actuator_states
Robot Description
aero_hand_open_description
Contains left and right URDF kinematics, 44 STL meshes, RViz2 display configs, and launch files.
ros2 launch aero_hand_open_description display.launch.py
Message Definitions
aero_hand_open_msgs
Custom IDL definitions for 16-joint angles, 7 actuator setpoints, telemetry packets, and mocap tracking.
JointControl.msg (float64[16])
ActuatorControl.msg (float64[7])
Teleoperation
aero_hand_open_teleop
Retargets human hand motions from Manus Quantum gloves or webcam MediaPipe tracking onto the hand.
ros2 launch aero_hand_open_teleop manus_teleop.launch.py
Reinforcement Learning Policy Deployment (MuJoCo Playground)
Z-Axis Object Rotation Policy
The repository includes aero_hand_open_rl, implementing a trained policy from MuJoCo Playground for in-hand manipulation. Run the communication node in Terminal 1 and deploy the RL policy in Terminal 2:
# Terminal 1: Hardware bridge
ros2 run aero_hand_open aero_hand_node

# Terminal 2: RL deployment node
ros2 run aero_hand_open_rl rl_z_rotation_deploy
